# Moja Nauka — итог архитектурной ревизии

**Статус:** целевая архитектура v2.0.0 утверждена для разработки, но реализация и совместимость на устройствах пока не проверены.

## Утверждённый стек

- Детское приложение: React + TypeScript + Vite, PWA для Android Chrome и iPad/iPhone Safari (через экран «Домой»).
- Админка: отдельный React + TypeScript + Vite на **другом HTTPS origin**.
- Supabase: Auth (только владелец), PostgreSQL, Edge Functions, private Storage.
- Офлайн: IndexedDB для HTML/каталога, Service Worker и Cache Storage для оболочки приложения.
- Уроки: один self-contained HTML до 20 MiB; проверка SHA-256; iframe с непривилегированным opaque origin; отдельная CSP через локальный виртуальный маршрут SW.
- Синхронизация: вся разрешённая библиотека, скачиваются только изменённые версии; каждый готовый урок устанавливается собственной атомарной транзакцией.

## Почему утверждено

Основное использование — дома при Wi-Fi. Нативная APK-инфраструктура и Capacitor bridge добавляли сложность ради редких офлайн-сценариев, тогда как PWA охватывает Android и Apple одним клиентом. При этом полноценный офлайн **остаётся P0**, а не заменяется случайным браузерным кэшем.

## Что сознательно НЕ обещаем

- Браузерное хранилище не равно Android Private Files: пользователь/браузер может очистить данные; PWA должна показать повторное подключение/загрузку.
- Токен в IndexedDB не защищён Android Keystore; защита строится на изоляции origin, CSP и отсутствии стороннего кода.
- Изоляция iframe защищает приложение, но не гарантирует полного запрета собственной навигации любого злонамеренного HTML во всех браузерах. Публикация только владельцем, lint и тесты обязательны.

## Условия перед полноценной реализацией

1. Получить оригинальный `fixtures/rocks-soil.html` — он не был приложен к исходным 10 MD-файлам. Ожидается 333 033 байта и SHA-256 `7590b609c72a5e454887707ed16a5e3de6bec759ea1fc2e88247f9654265566c`.
2. Пройти G1: реальный урок работает офлайн в sandboxed iframe через SW+IndexedDB на Android Chrome и Safari Home Screen; проверено отсутствие доступа к родительскому приложению и его данным.
3. Проверить в тестовом Supabase 20-MiB upload-finalize, корректный CORS signed uploads/downloads и управление версиями.
4. До релиза завершить обязательные функциональные/security тесты G0–G5 и зафиксировать результаты.
